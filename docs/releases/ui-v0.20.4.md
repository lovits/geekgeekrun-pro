# Geek Geek Run-Pro 0.20.4

本版本加入独立的 HR 消息自动回复、运行节奏配置与界面主题，并改进配置、记录和模板管理。

## 新增与改进

- 新增独立 HR 消息自动回复：可设置扫描范围、延迟、巡检及观察频率；支持简历、微信、电话工具开关及转人工记录。重新打开应用后需重新开启。
- 自动开聊支持按成功次数休息、定时计划；统一管理期望公司与屏蔽规则。
- 增加浅色、深色及跟随系统主题，优化页面布局与表单说明。
- 公司规则、职位正则、求职偏好及自动回复资料支持个人模板保存、套用与删除。
- 回复记录支持导出；模拟和开聊记录展示期望公司标记，应用设置集中管理配置与记录导出。
- 改进模型端点切换保存和 OpenAI 兼容请求；GitHub API 因限额返回 403／429 时，可从公开发布页面检查稳定版本。
- 多项守护进程、配置保存及运行边界修复。新安装不包含开发者个人配置与登录资料。

## 安装与注意事项

发布附件及 SHA-256 校验值见本页面。Mac 包为临时签名、未经过 Apple 公证；Windows 包未使用商业代码签名。自动开聊及 HR 自动回复可能发送真实消息或附件，使用前请检查设置并监督运行。AI 匹配结果仅供参考，应人工核对资格条件。旧版本若正遇到 GitHub API 限额，可能需要先手动从发布页面安装本版本。
